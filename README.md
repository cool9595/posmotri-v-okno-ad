# Посмотри в окно

Проект учебного спринта «Вёрстка. Доступность и подходы к организации стилей».

## Что умеет приложение

- получает видеокарточки из API Практикума;
- показывает первое видео и список результатов;
- фильтрует результаты по городу и времени суток;
- переключает основное видео по клику на карточку;
- подгружает следующую страницу результатов кнопкой «Показать еще»;
- показывает прелоадер и сообщение об ошибке.

## Запуск

Откройте `index.html` через локальный статический сервер. Например:

```bash
python3 -m http.server 8080
```

Затем перейдите на <http://localhost:8080>.

## Структура

- `index.html` — разметка страницы и шаблоны карточек;
- `styles/` — базовые, компонентные стили, прелоадер и состояние ошибки;
- `scripts/script.js` — запросы API, фильтрация, карточки и переключение видео;
- `fonts/` — шрифты проекта;
- `.github/workflows/tests.yml` — официальный визуальный workflow.
